
# Centralized Student Record Management System

## Project Description
The Centralized Student Record Management System is a
Java-based console application used to manage student
personal and academic information.

## Technologies Used
- Programming Language: Java
- IDE: Visual Studio Code
- Data Structure: Singly Linked List
- Storage: Text File Handling

## Features
1. Add Student Records
2. Search Student Records
3. Display All Students
4. Update Student Details
5. Delete Student Records
6. Attendance Management
7. Attendance Percentage Calculation
8. Student Marks Management
9. Academic Performance Reports
10. Text File Storage

## Java Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- Methods
- Singly Linked List
- ArrayList
- File Handling
- Exception Handling

## Files Used
- Main.java
- Student.java
- StudentLinkedList.java
- StudentFileHandler.java
- Attendance.java
- AttendanceFileHandler.java
- Marks.java
- MarksFileHandler.java
- ReportGenerator.java

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   javac *.java

5. Run the program:

   java Main

## Storage Files
- students.txt
- attendance.txt
- marks.txt

## Conclusion
This project provides a simple way to manage student
personal details, attendance and academic performance
using Java and a manually implemented Singly Linked List.
